Aldermere in Numbers — the official statistics site of the fictional country of Aldermere: an overview dashboard with key figures and sparklines, population, economy, health, education and environment sections with canvas line and bar charts, year and chart selectors, sortable tables, and a regions section with search, sorting and a detail page per region. Every figure names its source and year. Plain static files, no network requests, works on desktop and phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
